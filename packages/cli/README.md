# @mdts/cli

Write documents in TypeScript and use the `mdts` command to generate, check, and preview Markdown.

## Usage

Generate a guide for your project after [installing the package](#setup).
Create `mdts.config.ts` in your project root:

```ts
import { defineConfig } from '@mdts/core'

export default defineConfig({})
```

Create `content/guide.md.ts`:

```ts
import { defineMeta, md } from '@mdts/core'

export const meta = defineMeta({ title: 'Guide' })

export default md`
This document is written in TypeScript.
`
```

Run from the project root:

```bash
npx @mdts/cli build
```

Expected result: `dist/guide.md` contains:

```markdown
<!-- AI agents: This file is generated by mdts. Do not edit it directly. Edit the source .md.ts file instead. -->

# Guide

This document is written in TypeScript.
```

The build replaces `dist`, or the output directory selected in `mdts.config.ts`.
To validate these documents or preview them in your browser:

```bash
npx @mdts/cli lint
npx @mdts/cli preview
```

Lint exits with status 0 when no errors are found, or reports findings and exits nonzero without changing output files.
Preview prints a local URL where you can read `guide.md`. Stop it with Ctrl+C.
Only execute trusted document modules and configuration because they run as code.

## Key features

- Build `.md` files from your document modules.
- Check document dependencies and prose before publishing.
- Preview generated documents in a browser.

## Prerequisites

- Node.js 24 or later.
- A project with a `package.json`.

## Setup

### Install

```bash
npm install --save-dev @mdts/cli @mdts/core
```

Core supplies the authoring helpers used by document modules.
Keep core installed in your project so imports in documents and configuration can resolve it.

### Run without installing

```bash
npx @mdts/cli --help
```

## API

| Command        | Result                                                                                                        |
| -------------- | ------------------------------------------------------------------------------------------------------------- |
| `mdts build`   | Generate Markdown, replacing the configured output directory.                                                 |
| `mdts lint`    | Report document diagnostics to stderr and exit with status 1 when errors exist. Warnings alone keep status 0. |
| `mdts preview` | Start the document preview, print its URL, and close the server when interrupted.                             |

Each subcommand accepts `--config` or `-c` to select a configuration file.
Use `npx @mdts/cli --help` or `npx @mdts/cli build --help` to discover flags, and `npx @mdts/cli --version` for the installed version.
Configuration defaults to `mdts.config.ts` in the current directory.

The package exposes no authoring or programmatic library API.
Use [`@mdts/core`](../core/README.md#api) for configuration, compilation, lint diagnostics, and preview creation from code.
See the [core migration notes](../core/README.md#migration-from-01) when updating imports from version 0.1.
